# Mayank Kumar Portfolio — Vercel Ready

This folder is a standalone Vite + React version of the portfolio, separated from the original Replit monorepo.

## Vercel settings

- Root Directory: `.` (leave it empty in Vercel)
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`
- Install Command: `npm install`

The project does not require `PORT` or `BASE_PATH` environment variables.
